# Bruno API Practice

## 📌 About This Repository

This repository contains my hands-on practice of API testing using **Bruno API Client**.

Bruno is an open-source API testing tool used to send HTTP requests, test REST APIs, and inspect responses.

## 🎯 Learning Objectives

- Understand REST API testing
- Learn HTTP methods
- Send requests using Bruno
- Analyze API responses
- Practice CRUD operations
- Understand request headers and JSON bodies

## 🛠️ Tools & Technologies

- Bruno API Client
- REST API
- HTTP
- JSON
- ASP.NET Core Web API

## 📚 Concepts Covered

- GET Request
- POST Request
- PUT Request
- DELETE Request
- Request Headers
- JSON Request Body
- API Response
- HTTP Status Codes

## 🔄 HTTP Methods

| Method | Description |
|---|---|
| GET | Retrieve data |
| POST | Create new data |
| PUT | Update existing data |
| DELETE | Delete data |
